# 🐍 Python Projects

Small Python projects I built while learning Python through a Udemy Python bootcamp.

| Project | Description |
|---|---|
| [Blind Auction](Blind-Auction) | A command-line blind auction: each bidder enters a name and bid in private, then the highest bidder wins. |

## ▶️ Running a project

Each project lives in its own folder. You need Python 3, and no extra packages.

```bash
cd Blind-Auction
python3 Blind-Auction.py
```
